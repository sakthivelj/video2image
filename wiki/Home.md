# video2image

**Photogrammetry-focused video frame extractor** — a desktop GUI application for extracting frames from video files.

## What is video2image?

video2image is a Windows desktop application designed for extracting frames from video files. It's built specifically for photogrammetry workflows — 3D reconstruction from photographs — but works for any frame extraction task.

## Key Features

| Feature | Description |
|---------|-------------|
| **Key Frame Extraction** | Extracts only visually distinct frames — ideal for photogrammetry |
| **Scene Detection** | Captures frames at significant visual changes |
| **Motion-based** | Extracts frames with meaningful motion |
| **Duplicate Removal** | Skips near-identical frames |
| **Batch Processing** | Process entire folders with parallel execution |
| **Dark Theme** | Modern, comfortable interface |
